安裝前核對硬體

  • NVIDIA 專用 VRAM：32GB 等級或以上，另需確認 GPU 架構、驅動與 CUDA 相容性。
  • 系統實體 RAM：64GB 或以上，需另看當下可用量。
  • NVMe SSD：模型約 145GB，還需額外的安裝、快取、工作檔與輸出空間。
  • 作者本機平台為 Windows 11／NVIDIA；其他平台需另外驗證。

預留作業系統與其他程式使用的資源；一次只執行一項 GPU 工作。

作者使用 RTX 5090 32GB＋96GB RAM 實際製片；64GB RAM 另以模擬方式驗證。

硬體不足或不明時，先確認適用版本，再下載模型與安裝。閱讀作者完整硬體說明。

給未來協助安裝的 agent

先讀 AGENTS.md 與 hardware-requirements.json，核對本機 GPU、VRAM、實體／可用 RAM、NVMe 可用空間及相容性；不足或不明時先回報，避免直接進行大型下載及安裝。

GitHub Pages 僅提供靜態說明，AI 模型需在符合條件的電腦上另外安裝。
